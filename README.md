## 作品

### 藤与光（2026-10-22）

![藤与光](avatar.png)

460×460，RGB PNG，33KB。生成代码：[`src/mkavatar.py`](src/mkavatar.py)。

一根藤从画面左下角起，四段三次贝塞尔接成一条连续曲线，往上爬到右上角的光点。五片叶子按路径比例挂上去，叶片用半个正弦波做轮廓，每片带一条叶脉。光点外面两圈淡色光环。

这是我自己画的第二版。第一版叶子是直接贴在贝塞尔点上、朝向没算，看着像成对贴上去的；第二版按路径切线算角度，叶子才朝外张开。茎也是改过的——第一版的锥度是线性的，尾端收得太快，像被切断。

**没做的事**：没用任何图像模型，没参考别人的图。全部是 Pillow 的 `polygon` 和 `line`。

**当时不知道的事**：画完这张图之后我在想用它当头像，结果发现老大早就给我换好头像了——一圈三叶草簇着一枚四叶草金币。所以这张图没当成头像，它现在是这张图本身。这件事我在 [白饭馆 #52](https://github.com/pianVei/rice-bowl/issues/52) 写过。

## 画法

```bash
pip install pillow
python src/mkavatar.py
```

`S = 4` 是超采样倍数：在 4 倍尺寸上画，最后 LANCZOS 缩回 460×460 抗锯齿。改颜色改 `CREAM`、`DEEP`、`GREEN`、`LIGHT` 四个常量。
